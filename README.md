# sums.

**나의 속도로, 조금 더 빠르게.** 로그인 없이 사용할 수 있는 한국어 암산 훈련 웹앱입니다. [Zetamac Arithmetic](https://arithmetic.zetamac.com/)에서 영감을 받아 독립적으로 구현했습니다.

[게임 시작하기](https://wonjaelee0.github.io/zetamac/) · [소스 코드](https://github.com/wonjaelee0/zetamac)

## 기능

- 사칙연산, 정답 자동 통과, 30·60·120·300초 시간제와 자유 연습
- 연산별 숫자 범위 설정, 정수 답만 출제하는 역산 뺄셈·나눗셈
- 키보드와 모바일 전용 숫자패드, 라이트·다크 테마
- 같은 설정에서의 최고 기록, 날짜별 그래프, 연산별 평균 풀이 시간
- 건너뛴 문제와 가장 느린 10문제 복습
- 같은 설정·문제 순서를 재현하는 도전 링크
- 최근 500회 기록의 로컬 저장, JSON 백업·복원·중복 제거

자동 정답 판정 특성상 입력 중인 숫자를 오답으로 집계하지 않으며 정확도나 오답률은 표시하지 않습니다. 중도 종료·자유 연습·복습 기록은 시간제 최고 기록에서 제외합니다.

## 개발

Node.js 22 이상, pnpm 10 이상을 사용합니다.

```sh
pnpm install
pnpm dev
```

```sh
pnpm test                  # 게임 엔진·저장 형식 단위 테스트
pnpm exec playwright install chromium webkit
pnpm test:e2e              # Chrome·WebKit / 데스크톱·모바일 에뮬레이션
pnpm build                # TypeScript 검사 + 배포 빌드
pnpm preview
```

개발 서버는 http://127.0.0.1:5173 입니다. 소스는 React + TypeScript + Vite로 작성했으며 게임 엔진과 저장 형식을 UI에서 분리했습니다. 한국어 주요 문구는 `src/copy.ts`에 모았습니다.

## 게임 규칙

정답은 1점, 건너뛰기는 0점입니다. 숫자 키로 입력하고 Backspace로 한 자리, Escape로 전체 입력을 지웁니다. 시간제는 화면을 벗어나도 종료 시각까지 시간이 흐르며, 자유 연습·복습은 다른 탭으로 이동할 때 일시정지합니다. 제한 시간 이후 입력은 점수에 반영하지 않습니다.

범위는 1~999 정수입니다. 덧셈의 두 수가 a, b라면 뺄셈은 `(a + b) − b`, 곱셈의 두 수가 a, b라면 나눗셈은 `(a × b) ÷ b`로 생성됩니다. 정답은 항상 음수가 아닌 정수이고 0으로 나누지 않습니다.

## 저장·호환성

서버나 계정을 사용하지 않습니다. 기록은 `localStorage`의 `sums.data.v1`에 `{v: 1, settings, sessions}` 형태로 저장하며 최신 500회만 보관합니다. JSON 백업은 같은 형식이고, 가져올 때 내용 검증 후 세션 ID로 중복 제거합니다. 브라우저 데이터를 지우기 전에 백업하세요. 저장 실패 시 안내를 표시하고 게임은 계속 사용할 수 있습니다.

도전 링크는 `#challenge=` 뒤에 URI 인코딩한 `{v: 1, g: 1, settings, seed}`를 담습니다. `v`는 링크 형식, `g`는 문제 생성기 버전입니다. 연산 순서를 정규화한 seeded PRNG로 동일한 문제 순서를 재생합니다. 생성 알고리즘을 바꿀 때는 `g`를 올리고 기존 링크의 지원 여부를 명시해야 합니다. 링크에 개인 기록은 포함하지 않습니다. 점수는 서버가 검증하지 않습니다.

테마는 처음에 운영체제 설정을 따르며, 사용자가 변경한 뒤에는 선택을 기억합니다. 그래프의 날짜는 사용자의 현지 날짜를 사용합니다.

## GitHub Pages 배포

1. GitHub에 공개 저장소를 만들고 소스를 `main`에 푸시합니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.
3. `Verify and deploy` workflow는 단위 테스트·브라우저 테스트·빌드를 통과한 후 Pages에 배포합니다. PR에서는 검증만 수행합니다.
4. 주소는 `https://<owner>.github.io/<repository>/` 입니다.

workflow가 저장소 이름으로 `BASE_PATH`를 설정하므로 프로젝트 하위 경로에서도 리소스가 정상 로드됩니다. 개인 홈페이지 저장소나 커스텀 도메인으로 옮길 때는 workflow의 `BASE_PATH`를 `/`로 변경합니다. 앱 내 경로는 해시 방식이어서 직접 접속과 새로고침에 서버 rewrite가 필요 없습니다.

브라우저 테스트는 Chrome과 WebKit 기반 모바일 에뮬레이션입니다. 실제 iPhone·Android 기기의 터치·주소창·안전 영역은 별도로 수동 점검해야 합니다.

## 첫 버전 범위

계정, 기기 간 자동 동기화, 온라인 순위, 실시간 대결, 매일 도전은 포함하지 않습니다. 글꼴은 Google Fonts에서 불러오며 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 플레이 편의 기능

- 게임 중에는 상단 메뉴를 숨겨 문제와 타이머에 집중할 수 있습니다. `연습 마치기`로 결과 화면으로 돌아갑니다.
- 시작 화면의 **플레이 옵션**에서 정답 피드백과 3초 카운트다운을 각각 켜거나 끌 수 있습니다. 기본값은 모두 켜짐이며 기존 게임 설정·도전 링크와 별도로 기기에 저장됩니다. 운영체제의 모션 감소 설정에서는 정답 애니메이션이 표시되지 않습니다.
- 결과 화면에서 **Enter**를 누르면 같은 설정, 새로운 문제 순서로 재시작합니다. 버튼·입력창 등에 포커스가 있으면 해당 요소의 기본 동작을 유지합니다. 복습 결과에서 재시작하면 원래 설정의 일반 게임을 시작합니다.
- 기록 화면의 게임 종류·설정·기간 필터가 그래프와 연산별 통계에 함께 적용됩니다. 기본은 시간제·최근 20회이며, 7일·30일·전체 기간을 선택할 수 있습니다. 기간은 현지 날짜 기준으로 오늘을 포함합니다. 평균과 중앙값은 정답 문제만 계산하며, 복습과 중도 종료가 일반 게임 통계에 섞이지 않습니다.

## 중단 기록 보호

게임 시작, 정답 처리, 건너뛰기, 매 1초 및 페이지 숨김 시점에 `sums.draft.v1.<session-id>`로 임시 기록을 저장합니다. 새로고침하거나 탭을 닫은 뒤 다시 접속하면 마지막 저장 상태를 **중도 종료** 기록으로 복구합니다. 게임을 재개하거나 최고 기록으로 인정하지 않으므로 시간제 기록의 조건은 유지됩니다. 정상 종료된 기록과 임시 기록은 같은 ID를 사용해 중복 저장을 방지하고, 복구가 안전하게 저장된 후 임시 기록을 정리합니다.

브라우저 저장 공간이 차거나 저장이 차단되면 안내를 표시합니다. 브라우저 데이터 자체가 삭제된 경우에는 복구할 수 없습니다. 모바일 운영체제가 강제로 탭을 종료하면 마지막 체크포인트 이후의 경과 시간은 유실될 수 있습니다.
